# Rice Leaf Disease Detection Using CNN 🌾

## Project Overview
Rice Leaf Disease Detection Using CNN is a deep learning-based image classification project developed to identify diseases in rice plants by analyzing images of their leaves.

The project uses a Convolutional Neural Network (CNN) to automatically extract visual features from rice leaf images and classify them into different disease categories. It aims to assist in the early identification of rice plant diseases, helping improve crop health monitoring and support agricultural productivity.

## Key Features
- **Image Classification:** Automatically classifies rice leaf images into different disease categories.
- **CNN-Based Model:** Uses Convolutional Neural Networks for image feature extraction and classification.
- **Image Preprocessing:** Resizes and prepares images for model training.
- **Model Training:** Trains a deep learning model using a labeled rice leaf image dataset.
- **Performance Evaluation:** Evaluates the model using classification metrics such as accuracy, precision, recall, and F1-score.
- **Disease Identification:** Predicts the disease category based on the uploaded rice leaf image.

## Technology Stack
- **Programming Language:** Python
- **Deep Learning:** Convolutional Neural Network (CNN)
- **Libraries:** TensorFlow / Keras, NumPy, Pandas, Matplotlib
- **Image Processing:** Pillow / OpenCV
- **Development Environment:** Jupyter Notebook / Google Colab

## Project Objective
The primary objective of this project is to develop an automated rice leaf disease classification system using deep learning techniques. By applying CNN-based image recognition, the system aims to reduce manual inspection efforts and support faster disease identification in rice crops.
